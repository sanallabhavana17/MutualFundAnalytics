\# Bluestock Week 2 – FinTech Domain \& Software Development Fundamentals



\## Overview



This repository contains the Week 2 prerequisite assignments completed as part of the Data Analyst Internship – FinTech program.



The assignments focus on understanding financial markets, REST APIs and JSON, Git and GitHub, software architecture, and the FinTech business ecosystem.



\## Week 2 Deliverables



\### 1. Stock Market Fundamentals

\- Stock market concepts

\- NSE and BSE

\- Nifty and Sensex

\- Market capitalization

\- Financial ratios

\- Financial statement analysis



\### 2. REST APIs \& JSON

\- Public REST API request

\- JSON response inspection

\- JSON to Pandas DataFrame conversion

\- CSV data export



\### 3. Software Architecture

\- Client-server architecture

\- Frontend and backend

\- REST API

\- Database

\- ETL/data pipeline

\- Analytics dashboard



\### 4. FinTech Business Understanding

\- Zerodha case study

\- Demat accounts

\- NSDL and CDSL

\- SEBI

\- Trading lifecycle

\- Settlement process

\- Market participants

\- Data analytics in FinTech
