# Basic Software Development Concepts

## 1. Frontend vs Backend

Frontend is the part of an application that users see and interact with.
Backend works behind the scenes and handles business logic, APIs, and database communication.

## 2. Client-Server Architecture

The client is the application or browser used by the user.
The server processes requests and sends responses back to the client.

## 3. REST APIs

REST APIs allow different software applications to communicate using HTTP methods such as GET and POST.

## 4. Authentication

Authentication verifies the identity of a user before allowing access to protected resources.

## 5. Databases

Databases store and manage application data such as users, companies, stock prices, and financial information.

## 6. Data Pipelines

Data pipelines collect, clean, transform, and move data from sources to databases or analytics systems.

## 7. Logging

Logging records important application events, warnings, and errors so that developers can monitor and troubleshoot the system.

## 8. Error Handling

Error handling manages unexpected problems and prevents the application from failing without providing useful feedback.

## 9. Software Development Life Cycle (SDLC)

The Software Development Life Cycle describes the stages involved in developing and maintaining software.

The main stages are:

Requirements → Planning → Design → Development → Testing → Deployment → Maintenance
